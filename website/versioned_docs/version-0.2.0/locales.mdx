## Lookup rules

- Codes are case-insensitive and accept BCP-47 tags: `zh-cn`, `ZH_CN` and `zh_CN` are the same.
- An unknown region falls back to its language (`vi_VN` → `vi`), then to English.
- When a call passes no locale, [`DateFormatterConfig.locale`](./configuration.mdx) is used, then `Intl.defaultLocale`.
- `format` keeps the requested region for `intl` (`en_GB`, `pt_BR`) when `intl` has data for it.

```dart
SupportedLocalesUtils.getSupportedLocales();         // pattern + relative
SupportedLocalesUtils.getSupportedRelativeLocales(); // also relative-only locales
SupportedLocalesUtils.isLocaleSupported('de_DE');    // true
```
