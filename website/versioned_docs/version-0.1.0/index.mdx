# Getting started

`flutter_date_formatter` formats, parses and computes dates in 55+ locales. It works in any Dart or Flutter project and adds no setup step: the `intl` date data is loaded on first use.

Every example on this site runs the real package, compiled from Dart to JavaScript. Change the inputs, switch the **locale** in the dark bar, and copy the code.

## Install

<Steps>
<Step title="Add the package">

```bash
dart pub add flutter_date_formatter
# or, in a Flutter app
flutter pub add flutter_date_formatter
```

</Step>
<Step title="Import it">

```dart
import 'package:flutter_date_formatter/flutter_date_formatter.dart';
```

</Step>
<Step title="Format a date">

```dart
final date = DateTime(2025, 3, 21, 15, 30);

date.format(pattern: 'do MMMM yyyy');           // 21st March 2025
date.formatRelative(locale: 'vi');              // 3 giờ trước
date.formatCalendar();                          // Yesterday at 3:30 PM
const Duration(hours: 2, minutes: 5).humanize(); // 2 hours 5 minutes
```

</Step>
</Steps>
